
# scRNA-seq-analysis

Analysis workflows and code for single-cell RNA sequencing (scRNA-seq) data.

## Repository Contents

* `figures/` — generated UMAPs, dot plots, and other analysis figures.
* `results/` — marker tables, annotation results, stage audits, macrophage analyses, and supporting results.
* `scripts/` — analysis scripts.
* `data/` — project data files suitable for GitHub.
